# Neural Navigators website

Plain static site (HTML + CSS, no build step), hosted on GitHub Pages.

- Pages: `index.html`, `about.html`, `services.html`, `contactus.html` (served at `/`, `/about`, `/services`, `/contactus`)
- `assets/css/style.css` – all styles; colors and fonts are variables at the top
- `assets/js/main.js` – mobile menu and contact form
- `assets/img/` – logos, photos, favicon

The header and footer are repeated in each page; change all four if you edit them.

To update the site, edit the files and push to `main`; GitHub Pages redeploys automatically.
