# Neural Navigators website

Single-page static site (HTML + CSS + a little JS, no build step), hosted on GitHub Pages.

- `index.html` – the whole site: Home, About, Services, Contact sections
- `assets/css/style.css` – all styles; colors and fonts are variables at the top
- `assets/js/main.js` – nav highlighting, parallax, scroll animations, service tabs, mobile menu, contact form
- `assets/img/` – logos, photos, favicon
- `about.html`, `services.html`, `contactus.html` – redirect old page links to the matching section

To update the site, edit the files and push to `main`; GitHub Pages redeploys automatically.
